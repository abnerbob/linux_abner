yield关键字：将一个函数变成一个“生成器“  (生成器/生成器对象) 生成器是特殊的迭代器

当程序运行到 yield 时，函数会做三件事：
暂停：保存当前的变量状态（函数内局部变量的值）。
交出控制权：返回一个值给调用者，并暂时把 CPU 控制权还给外层。
原地待命：下一次再调用该生成器时，它会从 yield 紧接着的下一行代码继续执行，而不是从头开始。

yield是否破坏函数的单一权责原则？
1.为了“闭包”的极致优化：如果不用 yield，你要实现同样的功能，通常需要写一个类（Class），包含 __iter__ 和 __next__ 方法。那个类需要维护 self.index、self.state 等各种成员变量。相比于写一个复杂的类，yield 让你用函数的形式就完成了“状态机”的功能。
2.在 Python 的哲学里，带有 yield 的函数不再是传统意义上的“函数（Function）”，它是“生成器工厂（Generator Factory）”。它的职责单一且明确：“如何按顺序产生这一系列数据”。

dict.items() 本身产生的是一个视图对象（View Object），里面是一堆 (key, value) 的元组。在for循环中迭代，每次会拷贝生成一个临时的元组给for，使用完释放
dict在for循环中返回的是key值，不会返回(key, value)

dict_items(视图对象)支持集合运算，运算后的结果是集合。本质运算符重载

(生成器/生成器对象)

1. 仅是“可迭代对象” (Iterable Only)
特征：它们是纯粹的数据容器。它们实现了 __iter__（能生出游标），但没有 __next__ 方法。你可以对它们进行无限次 for 循环，因为每次循环都会重新 new 一个独立的游标，数据永远不会被“耗尽”。
list (列表)：如 [1, 2, 3]
tuple (元组)：如 (1, 2, 3)
str (字符串)：如 "hello"
dict (字典)：如 {'a': 1}
set (集合)：如 {1, 2, 3}
bytes (字节序列)：如 b"hello"
range (范围对象)：如 range(10)
⚠️ 特别注意 range：这是最容易翻车的地方！很多人以为 range(10) 是个懒加载的东西，它一定是迭代器。不，它只是可迭代对象。 > 你可以写 r = range(5); for x in r: pass 跑完之后，再跑一次 for x in r: pass 依然能打印出东西。它没有内部指针状态的消耗，所以它不是迭代器。

2. 既是可迭代对象，又是“迭代器” (Iterator)
特征：它们是数据流/状态机。它们同时实现了 __iter__ 和 __next__。它们内部维护着一个“指针”，只能一路向前，读完一次就彻底报废（耗尽）。
generator (生成器)：包括用 yield 写的函数，以及用小括号写的生成器表达式 (x for x in range(10))。
enumerate (枚举对象)：如 enumerate(['a', 'b'])
zip (拉链对象)：如 zip([1, 2], ['a', 'b'])
filter / map (过滤器/映射对象)：如 filter(None, [1, 2])
reversed (反转对象)：如 reversed([1, 2, 3])
文件对象 (File Object)：如 open('test.txt', 'r')
💡 为什么文件对象是迭代器？ 因为文件在底层是由操作系统内核维护的一个文件描述符（FD）和文件指针。你每读一行（调用 next()），指针就往前挪一步。文件读到末尾（EOF）就读不出东西了，无法自动重置。这极其符合迭代器的定义。
所有显式转换后的“游标对象”：如 list_iterator（通过 iter([]) 产生）、dict_keyiterator（通过 iter({}.keys()) 产生）。

闭包

闭包是一个现象。 当一个嵌套的内部函数，引用了外部函数的临时变量，并且外部函数把这个内部函数当成对象返回出去时，这个内部函数就形成了一个闭包。
```
def make_multiplier(x):
    # x 是外部函数的临时变量
    def multiply(n):
        return n * x  # 内部函数引用了外部的 x
    return multiply   # 把内部函数做成商品返回出去

# 制造一个“乘以 3”的闭包
triple = make_multiplier(3) 

# 此时 make_multiplier 函数已经执行完毕、弹栈销毁了！
# 但是变量 3 已经被 triple 永远绑架在它的隐形背包（__closure__属性）里了

print(triple(5))  # 输出 15 (5 * 3)
```

# 3. 正常调用（用户感知不到任何变化）
say_hello()

内建装饰器|它的本质（底层视角）|核心使用场景
@property|劫持属性读写，转为函数描述符。|动态计算、只读控制、向后兼容旧接口。
@classmethod|拦截调用，自动把当前**“类本身（cls）”**作为第一个参数传进去。|工厂模式。比如用 From_Elf_File(path) 或 From_Json(data) 等多种渠道去实例化同一个对象。
@staticmethod|切断与类和实例的联系。把它贬为类命名空间底下的一个普通静态函数。|纯工具函数。不需要读写 self 或 cls 的状态，纯粹因为逻辑相关把它挂在类底下。

self 指向的是“实例对象”，而 cls 指向的是“类对象本身”。

```
class Firmware:
    vendor = "Intel"  # 类变量（存在类对象里）

    def __init__(self, version):
        self.version = version  # 实例变量（存在具体的实例里）

    # 1. 普通方法：绑定实例指针 self
    def get_info(self):
        return f"当前固件版本: {self.version}"

    # 2. 类方法：绑定类指针 cls
    @classmethod
    def get_vendor(cls):
        # 拿不到具体实例的 version，但能拿到类的通用属性 vendor
        return f"厂家是: {cls.vendor}"

    # 3. 静态方法：谁都不绑，普通的 C 函数
    @staticmethod
    def is_valid_hex(string):
        return True
```

魔法方法（语法糖外壳）,具象作用大白话（底层物理本质）,典型工程场景
__str__,print(obj) 或 str(obj),人眼可读字符串。控制对象被打印时的长相，把内存地址换成你看得懂的日志信息。,打印配置、打 Debug 日志。
__iter__,for item in obj:,开启迭代器。告诉虚拟机这个对象可以被循环遍历，必须返回一个带 __next__ 的指针对象。,遍历符号表、遍历文件行。
__getitem__,value = obj[key],中括号索引劫持。让你的对象可以像 list 或 dict 一样，用中括号去取值。,读写寄存器阵列、解析配置项。
__getattr__,obj.not_exist_var,兜底哨兵。只有当访问的属性不存在时，才会触发这个函数。用来拦截和动态处理未定义的变量。,动态代理、RPC 远程方法调用。
__call__,obj(),对象函数化。让一个实例出来的对象，可以像普通函数一样直接加括号调用。,编写带有状态的自定义装饰器。

```
# __str__和__repr__ 
class Student(object):
    def __init__(self, name):
        self.name = name
    def __str__(self):
        return 'Student object (name=%s)' % self.name
    __repr__ = __str__
__repr__为调试服务，直接输入变量，返回该内容；print变量返回__str__内容

# __iter__
class BuildPipeline:
    def __init__(self):
        # 内部具体的任务列表
        self._tasks = ["gcc_compile", "link_objects", "strip_symbols", "generate_hex"]

    # yield将__iter__变成了生成器
    def __iter__(self):
        print("\n▶️ [虚拟机通知]：触发了 __iter__ 魔法，迭代通道已建立")
        
        # 核心机械结构：用 yield 挨个把任务指针吐出去
        for task in self._tasks:
            yield task  # 👈 每次走到这，函数就会暂停，把 task 吐给外面的 for 循环

# __iter__和__next__
class CountToThree:
    def __init__(self):
        self.current = 0  # 显式维护的底层游标（指针）

    # 1. 握手阶段：循环开始前，虚拟机只调一次这个方法
    def __iter__(self):
        self.current = 0  # 计数复位（把指针拨回起点）
        return self       # 返回自己，因为 __next__ 就在我自己身上

    # 2. 索要货物阶段：虚拟机每次循环都在疯狂调这个方法
    def __next__(self):
        if self.current < 3:
            self.current += 1    # 指针物理步进
            return self.current  # 👈 返回具体的货物数据（1, 2, 3）
        else:
            raise StopIteration  # 👈 没货了，物理拉闸，抛出中断信号

# __getitem__
class Fib(object):
    def __getitem__(self, n):
        a, b = 1, 1
        for x in range(n):
            a, b = b, a + b
        return a

# __getattr__
class Student(object):
    def __getattr__(self, attr):
        if attr=='age':
            return lambda: 25

```

type()函数既可以返回一个对象的类型，又可以创建出新的类型
```
>>> def fn(self, name='world'): # 先定义函数
...     print('Hello, %s.' % name)
...
>>> Hello = type('Hello', (object,), dict(hello=fn)) # 创建Hello class
>>> h = Hello()
>>> h.hello()
Hello, world.
>>> print(type(Hello))
<class 'type'>
>>> print(type(h))
<class '__main__.Hello'>

```

metaclass 元类
```
# metaclass是类的模板，所以必须从`type`类型派生：
class ListMetaclass(type):
    def __new__(cls, name, bases, attrs):
        attrs['add'] = lambda self, value: self.append(value)
        return type.__new__(cls, name, bases, attrs)

class MyList(list, metaclass=ListMetaclass):
    pass

```

维度,类变量（Class Var）,实例变量（Instance Var）
定义位置,类块以内，方法以外,__init__（或其他方法）体内，必须挂在 self. 后面
内存份数,全局唯一（绑定在类对象上）,每 New 一个就多一份（绑定在实例对象上）
修改后果,通过类名修改，全员同步变化,修改只影响当前实例自己，别人无感
C语言硬核对齐,static 全局变量 / 符号表常量,结构体内部的普通 member 字段

方法类型,装饰器外壳,默认首位参数（指针）,读写实例变量 (self.x),读写类变量 (cls.x),核心工程战场（常见场景）,底层物理本质大白话
实例方法(Instance Method),无（默认）,self(指向当前具体实例对象),"🟢 直接读写self.name = ""A""",🟢 间接读写通过 self.__class__.var 或 Class.var,绝大多数普通的业务逻辑、需要频繁修改或读取具体对象自身状态的场景。,大内总管：手里攥着具体某个对象的专属钥匙，既能管实例家里的事，也能通过后门动老家（类）的账。
类方法(Class Method),@classmethod,cls(动态指向当前类对象本身),❌ 无法访问(因为没有传入 self 指针，它完全不知道具体是哪一个实例在调它),🟢 直接动态读写cls.total_count += 1(支持继承，子类调用时自动指向子类),1. 工厂模式（提供不同的参数解析和初始化路径去 return 一个新实例）。2. 全局状态维护（统一修改类的全局配置、计数器等）。,账房先生：不归任何一个具体对象管，级别更高。只对整个家族（类对象）的公账负责，动态调整全局配置。
静态方法(Static Method),@staticmethod,无(像普通函数一样，传什么就是什么),❌ 无法访问(完全拿不到实例的内存指针),🟡 只能硬编码访问必须指名道姓地写死类名：Robot.total_count += 1(不支持继承动态绑定),1. 纯工具计算（不依赖任何内存状态的纯数学、加密、硬件编码校验函数）。2. 代码归类封装（逻辑上只为该类服务，防止污染全局符号表）。,外聘工具人：跟类内部的内存状态（堆区）基本完全绝缘。只是借用一下类的名字空间（Namespace）落个脚。

单元测试模块 unittest
以test开头的方法就是测试方法，不以test开头的方法不被认为是测试方法，测试的时候不会被执行
```
import unittest

from mydict import Dict

class TestDict(unittest.TestCase):
    def test_init(self):
        d = Dict(a=1, b='test')
        self.assertEqual(d.a, 1)
        self.assertEqual(d.b, 'test')
        self.assertTrue(isinstance(d, dict))

    def test_key(self):
        d = Dict()
        d['key'] = 'value'
        self.assertEqual(d.key, 'value')

# 可以不用写main函数的调用，用来兼容老版本
if __name__ == '__main__':
    unittest.main()
```
