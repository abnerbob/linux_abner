yield关键字：将一个函数变成一个“生成器“  (生成器/生成器对象) 生成器是特殊的迭代器

当程序运行到 yield 时，函数会做三件事：
暂停：保存当前的变量状态（函数内局部变量的值）。
交出控制权：返回一个值给调用者，并暂时把 CPU 控制权还给外层。
原地待命：下一次再调用该生成器时，它会从 yield 紧接着的下一行代码继续执行，而不是从头开始。

yield是否破坏函数的单一权责原则？
1.为了“闭包”的极致优化：如果不用 yield，你要实现同样的功能，通常需要写一个类（Class），包含 __iter__ 和 __next__ 方法。那个类需要维护 self.index、self.state 等各种成员变量。相比于写一个复杂的类，yield 让你用函数的形式就完成了“状态机”的功能。
2.在 Python 的哲学里，带有 yield 的函数不再是传统意义上的“函数（Function）”，它是“生成器工厂（Generator Factory）”。它的职责单一且明确：“如何按顺序产生这一系列数据”。

dict.items() 本身产生的是一个视图对象（View Object），里面是一堆 (key, value) 的元组。在for循环中迭代，每次会拷贝生成一个临时的元组给for，使用完释放
dict在for循环中返回的是key值，不会返回(key, value)

dict_items(视图对象)支持集合运算，运算后的结果是集合。本质运算符重载

迭代器（Iterator）：实现了 __next__ 和 __iter__ 的类。它的作用是执行挨个取值的动作。

生成器表达式本身是生成器，返回的是一个生成器对象(也是可迭代对象)
(生成器/生成器对象)

1. 仅是“可迭代对象” (Iterable Only)
特征：它们是纯粹的数据容器。它们实现了 __iter__（能生出游标），但没有 __next__ 方法。你可以对它们进行无限次 for 循环，因为每次循环都会重新 new 一个独立的游标，数据永远不会被“耗尽”。
list (列表)：如 [1, 2, 3]
tuple (元组)：如 (1, 2, 3)
str (字符串)：如 "hello"
dict (字典)：如 {'a': 1}
set (集合)：如 {1, 2, 3}
bytes (字节序列)：如 b"hello"
range (范围对象)：如 range(10)
⚠️ 特别注意 range：这是最容易翻车的地方！很多人以为 range(10) 是个懒加载的东西，它一定是迭代器。不，它只是可迭代对象。 > 你可以写 r = range(5); for x in r: pass 跑完之后，再跑一次 for x in r: pass 依然能打印出东西。它没有内部指针状态的消耗，所以它不是迭代器。

2. 既是可迭代对象，又是“迭代器” (Iterator)
特征：它们是数据流/状态机。它们同时实现了 __iter__ 和 __next__。它们内部维护着一个“指针”，只能一路向前，读完一次就彻底报废（耗尽）。
generator (生成器)：包括用 yield 写的函数，以及用小括号写的生成器表达式 (x for x in range(10))。
enumerate (枚举对象)：如 enumerate(['a', 'b'])
zip (拉链对象)：如 zip([1, 2], ['a', 'b'])
filter / map (过滤器/映射对象)：如 filter(None, [1, 2])
reversed (反转对象)：如 reversed([1, 2, 3])
文件对象 (File Object)：如 open('test.txt', 'r')
💡 为什么文件对象是迭代器？ 因为文件在底层是由操作系统内核维护的一个文件描述符（FD）和文件指针。你每读一行（调用 next()），指针就往前挪一步。文件读到末尾（EOF）就读不出东西了，无法自动重置。这极其符合迭代器的定义。
所有显式转换后的“游标对象”：如 list_iterator（通过 iter([]) 产生）、dict_keyiterator（通过 iter({}.keys()) 产生）。

闭包

闭包是一个现象。 当一个嵌套的内部函数，引用了外部函数的临时变量，并且外部函数把这个内部函数当成对象返回出去时，这个内部函数就形成了一个闭包。
```
def make_multiplier(x):
    # x 是外部函数的临时变量
    def multiply(n):
        return n * x  # 内部函数引用了外部的 x
    return multiply   # 把内部函数做成商品返回出去

# 制造一个“乘以 3”的闭包
triple = make_multiplier(3) 

# 此时 make_multiplier 函数已经执行完毕、弹栈销毁了！
# 但是变量 3 已经被 triple 永远绑架在它的隐形背包（__closure__属性）里了

print(triple(5))  # 输出 15 (5 * 3)
```


装饰器 (装饰器本质上就是一个高阶闭包函数，不改变原函数情况下，给函数扩展功能)
```
# 1. 编写装饰器（大管家）
def my_decorator(func):
    def wrapper():
        print("--- 1. 核心代码执行前：偷偷加戏（如检查登录、记录日志） ---")
        func()  # 👈 2. 真正去执行你的原函数
        print("--- 3. 核心代码执行后：收尾工作 ---")
    return wrapper

# 2. 使用装饰器（戴帽子）
@my_decorator      # 等价 say_hello = my_decorator(say_hello)
def say_hello():
    print("      🚀 Hello World! (我是核心业务) ")

# 3. 正常调用（用户感知不到任何变化）
say_hello()

```

偏函数
偏函数来自 Python 内置的 functools 模块。它的核心作用是：固定住一个函数的某些参数，然后给你打包生成一个参数更少的“船新函数”。
```
from functools import partial

# 🎯 制造一个偏函数：把 int 函数的 base 参数永远焊死在 2 上
int_bin = partial(int, base=2)

# 以后你再用的时候，只需要传具体的字符串就行了！
print(int_bin('1010'))  # 输出 10
print(int_bin('1111'))  # 输出 15
```
